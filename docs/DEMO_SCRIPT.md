## Pre-flight checklist (Mon Jun 1)

- [ ] Real client willing to be in the video (or use a real recorded engagement with permission)
- [ ] All 5 hero metrics nailed down (no placeholder numbers)
- [ ] Lovable build URL reliably under 60 seconds
- [ ] Observability dashboard renders with real traces
- [ ] Simulation report PDF exists
- [ ] BigQuery eval table has ≥50 rows
- [ ] GitHub repo public and clone-tested in fresh env

## Filming notes

- Shoot in front of a clean background (no Rubicx branding visible — the story is Atlas).
- Use a real microphone (not laptop mic). USB condenser is fine.
- 1080p, 30fps. Vertical-friendly framing for cropped social cuts later.
- B-roll: record agent graph zooming + the live phone shot in separate takes; cut together in post.
- Captions: burn in for the first 15 seconds, soft subtitles thereafter (English required by submission rules).

## Cut notes

- Cut to 2:55 max. Builds in 5 seconds of buffer in case YouTube re-encoding adds latency.
- Music: light, electronic, low-energy. No vocal tracks.
- End card displays for 5 seconds with GitHub + Medium URLs.
